# Backup

This folder keeps previous implementations and unused assets so the live project can stay clean while still preserving recovery points.

- `*_backup.*`: Previous implementation snapshots kept for reference only.
- `assets_backup/`: Unused assets moved out of the public runtime surface.
- `assets_backup/hero-background_backup.mp4`: Replaced hero video kept as an unused asset backup.
