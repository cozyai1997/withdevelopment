# Services page image replacement

The `/services` page reads these files directly:

- `hero.png`: top hero background
- `service-01.png`: structure demolition card
- `service-02.png`: remodeling demolition card
- `service-03.png`: permit support card
- `service-04.png`: redevelopment demolition card

Replace a file with the same name to update the page without changing code.
Use privacy-safe images with no faces, car plates, detailed addresses, or personal data.
